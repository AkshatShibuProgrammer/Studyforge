### 1. Text Generation & Analysis
**Function Name:** `geminiGenerateText(promptText)`
**Input:** 
- `promptText` (String): The detailed prompt or instruction you want to send to the AI.
**Output:** 
- (String) The markdown-formatted text response from Gemini 3 Flash.
**How to Utilize:**
Use this whenever you need to summarize text, answer questions, analyze data, or generate content. You can take the output string and render it in the UI using a Markdown parser (like marked.js) or `dangerouslySetInnerHTML` if you process it yourself.

```javascript
// Implementation to include in your code:
async function geminiGenerateText(promptText) {
    const apiKey = ""; 
    const apiUrl = `https://generativelanguage.googleapis.com/v1beta/models/gemini-3-flash-preview:generateContent?key=${apiKey}`;
    const response = await fetch(apiUrl, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ contents: [{ parts: [{ text: promptText }] }] })
    });
    if (!response.ok) throw new Error(`API Error: ${response.status}`);
    const result = await response.json();
    return result?.candidates?.[0]?.content?.parts?.[0]?.text || "No text generated.";
}
```

### 3. Image Generation
**Function Name:** `geminiImageCreation(imagePrompt)`
**Input:** 
- `imagePrompt` (String): A highly descriptive, visual prompt detailing what the image should look like.
**Output:** 
- (String) A base64-encoded Data URL (e.g., `data:image/png;base64,iVBORw0KGgo...`).
**How to Utilize:**
Use this whenever the user requests a visual asset or infographic. The output is a raw base64 string, meaning you can directly inject it into the `src` attribute of an `<img>` tag in HTML/React without needing to download or host the image anywhere. Example: `<img src={await geminiImageCreation("a cat")} />`

```javascript
// Implementation to include in your code:
async function geminiImageCreation(imagePrompt) {
    const apiKey = ""; 
    const apiUrl = `https://generativelanguage.googleapis.com/v1beta/models/imagen-4.0-generate-001:predict?key=${apiKey}`;
    const response = await fetch(apiUrl, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
            instances: [{ prompt: imagePrompt }],
            parameters: { sampleCount: 1, aspectRatio: "16:9" }
        })
    });
    if (!response.ok) throw new Error(`API Error: ${response.status}`);
    const result = await response.json();
    const base64Encoded = result?.predictions?.[0]?.bytesBase64Encoded;
    if (!base64Encoded) throw new Error("No image data returned.");
    return `data:image/png;base64,${base64Encoded}`;
}
```
