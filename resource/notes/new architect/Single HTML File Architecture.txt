**SUBJECT: StudyForge — Mandatory Single HTML File Architecture Specification**

---

**CRITICAL CONSTRAINT:**

StudyForge must be delivered as **ONE single `.html` file**. This is non-negotiable. The entire application (HTML structure, CSS styling, JavaScript logic, prompt library, state management) must live inside a single file that can be double-clicked to run — no installation, no build step, no backend server, no external files (except CDN libraries loaded at runtime).

The user must be able to:
- Save the file to a USB drive and open it on any computer
- Double-click the file and see the app running immediately
- Refresh the browser and see their previous session restored
- Never need to install Node.js, npm, or any development tools

Follow this exact architecture pattern proven to work for zero-backend SPAs:

**Save State (JSON Serialization):**

`localStorage` only stores strings, so convert the object to a string with `JSON.stringify()`:

```javascript
const State = {
  save() {
    try {
      const serialized = JSON.stringify(appState);
      localStorage.setItem('studyforge_state', serialized);
    } catch (e) {
      console.error('State save failed:', e);
      // Handle quota exceeded, etc.
    }
  },
  
  load() {
    try {
      const saved = localStorage.getItem('studyforge_state');
      if (saved) {
        Object.assign(appState, JSON.parse(saved));
        return true;
      }
      return false;
    } catch (e) {
      console.error('State load failed:', e);
      return false;
    }
  },
  
  reset() {
    localStorage.removeItem('studyforge_state');
    // Reset appState to defaults
  }
};
```

### **PILLAR 3: JSON Communication with Gemini AI**

All AI calls use JSON in and JSON out.

**The API Namespace:**

```javascript
const API = {
  GEMINI_URL: 'https://generativelanguage.googleapis.com/v1beta/models/gemini-pro:generateContent',
  
  // Standard call (non-streaming)
  async callGemini(prompt, options = {}) {
    const payload = {
      contents: [{ parts: [{ text: prompt }] }],
      generationConfig: {
        temperature: options.temperature || 0.3,
        maxOutputTokens: options.maxTokens || 8192,
        responseMimeType: options.jsonOutput ? "application/json" : "text/plain"
      }
    };
    
    // Add grounding/search if enabled (for CA prompts)
    if (options.grounding) {
      payload.tools = [{ googleSearchRetrieval: {} }];
    }
    
    try {
      const response = await fetch(this.GEMINI_URL, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(payload)
      });
      
      if (!response.ok) {
        throw new Error(`API error: ${response.status}`);
      }
      
      const data = await response.json();
      return data.candidates[0].content.parts[0].text;
      
    } catch (error) {
      return this.handleError(error, prompt, options);
    }
  },
  
  // Streaming call (for text generation with live typing effect)
  async streamGenerate(prompt, onChunk, options = {}) {
    const streamUrl = this.GEMINI_URL.replace(
      ':generateContent', 
      ':streamGenerateContent?alt=sse'
    );
    
    const payload = {
      contents: [{ parts: [{ text: prompt }] }],
      generationConfig: { 
        temperature: options.temperature || 0.3 
      }
    };
    
    const response = await fetch(streamUrl, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(payload)
    });
    
    const reader = response.body.getReader();
    const decoder = new TextDecoder();
    let buffer = '';
    
    while (true) {
      const { value, done } = await reader.read();
      if (done) break;
      
      buffer += decoder.decode(value, { stream: true });
      const lines = buffer.split('\n');
      buffer = lines.pop(); // Keep incomplete line for next iteration
      
      for (const line of lines) {
        if (line.startsWith('data: ')) {
          const jsonStr = line.substring(6).trim();
          if (jsonStr === '[DONE]') continue;
          
          try {
            const data = JSON.parse(jsonStr);
            const text = data.candidates?.[0]?.content?.parts?.[0]?.text;
            if (text) onChunk(text);
          } catch (e) {
            // Chunk might be cut mid-JSON, skip and wait for next
            console.warn('Chunk parse error:', e);
          }
        }
      }
    }
  },
  
  // Universal error handler
  async handleError(error, originalPrompt, options) {
    // Auto-retry logic (2 retries with delay)
    // Show error popup with recovery options
    // Return null if user cancels
  }
};
```

**Why streaming matters:**
- User sees text appearing in real-time (like ChatGPT)
- Better perceived performance
- Can render containers as they arrive

## **PART 3 — WHAT NOT TO DO**

Do NOT:
- ❌ Create separate `.js` files (like `main.js`, `state.js`)
- ❌ Create separate `.json` files (like `prompts.json`, `config.json`)
- ❌ Create separate `.css` files (like `styles.css`)
- ❌ Use `require()` or `import` statements
- ❌ Use `module.exports` or ES6 modules
- ❌ Require any npm packages
- ❌ Require any build tools (Webpack, Vite, Parcel, etc.)
- ❌ Use any framework that requires a build step (React JSX, Vue SFC, etc.)
- ❌ Require a local server to run
- ❌ Use `fetch()` to load local JSON files (won't work with `file://` protocol)

Do:
- ✅ Put ALL JavaScript inside ONE `<script>` tag in the HTML file
- ✅ Put ALL CSS inside ONE `<style>` tag in the HTML file
- ✅ Store ALL prompts as JavaScript constants (not JSON files)
- ✅ Store ALL configuration as JavaScript objects
- ✅ Load external libraries only from CDNs
- ✅ Use vanilla JavaScript OR runtime-only frameworks (like Tailwind CDN)
- ✅ Test by double-clicking the file (opens with `file://` protocol)
