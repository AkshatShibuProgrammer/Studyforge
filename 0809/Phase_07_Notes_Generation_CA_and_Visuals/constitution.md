# Constitution: Phase 07 — Notes Synthesis, CA & Visuals

## 1. Principles
### Rule 1: Repeal of Plain Text Limitation
The legacy instruction `safe_content must be plain text only` is PERMANENTLY REPEALED. Note blocks MUST output rich structured Markdown (bold concepts, tables, step lists, LaTeX math notation) for rendering into pedagogical containers.

### Rule 2: Pre-Generation Current Affairs Swarm
Before calling AI-07A to write a part's notes, the system MUST execute grounded search queries formulated in the blueprint and feed verified facts directly into the note generation prompt.

### Rule 3: Self-Explanatory Visual Pair Mandate
No generated image may appear without an accompanying structured breakdown block containing:
1. Numbered Component Legend
2. Process / Lifecycle Narrative
3. Exam Takeaway

### Rule 4: Traceability Tagging
Every generated container block MUST carry one of 4 strict traceability markers:
`SOURCE_BACKED`, `RESEARCH_REQUIRED`, `OPTIONAL_ENRICHMENT`, or `WEB_SOURCED`.
