# Phase 04: Pedagogical Part Splitting & Structure

## Executive Summary
Phase 04 governs Screen 4 (Parts Planning). It analyzes document size, deep analysis entities, and active feature bundles to logically split content into 3 to 15 teachable parts adhering to pedagogical density guardrails, with interactive reordering, merging, and configuration.

## Module Breakdown
- `Mod_01_AI_Part_Splitting_AI04`: Density heuristics, page guardrails & unassigned topic prevention.
- `Mod_02_Part_Operations_Manager`: Part reorder (Up/Down), merge, add, remove & stale propagation.
