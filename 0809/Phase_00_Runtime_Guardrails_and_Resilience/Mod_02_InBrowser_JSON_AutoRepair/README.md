# Module 02: In-Browser JSON Auto-Repair (`Mod_02_InBrowser_JSON_AutoRepair`)

## Overview
`Mod_02_InBrowser_JSON_AutoRepair` implements a zero-dependency client-side parser that rescues truncated, malformed, or syntax-corrupted JSON emitted by large language models when reasoning tokens exceed output budgets.

---

## Deliverables in this Module
* 📜 **`constitution.md`**: Zero-crash mandates and non-destructive parsing rules.
* 📐 **`spec.md`**: Algorithms for quote closure, bracket balancing, and dangling key pruning.
* 📋 **`contracts.md`**: Repair data structures and diagnostic log formats.
* 🏗️ **`plan.md`**: State machine design for bracket stack tracking.
* 📌 **`tasks.md`**: Unit test suites covering synthetic truncation cases.
