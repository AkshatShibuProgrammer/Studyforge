# Module 01: Canvas AI Bridge (`Mod_01_Canvas_AI_Bridge`)

## Overview
`Mod_01_Canvas_AI_Bridge` provides the unified HTTP client for StudyForge. It interacts directly with Google's Generative AI REST endpoints from inside the browser without requiring external SDKs, backend daemons, or user-provided API keys.

---

## Deliverables in this Module
* 📜 **`constitution.md`**: Ambient key rules, timeout standards, and retry policies.
* 📐 **`spec.md`**: Requirements for text generation, search grounding, and image synthesis.
* 📋 **`contracts.md`**: Request and response interfaces and option definitions.
* 🏗️ **`plan.md`**: Implementation steps for fetch client and backoff loops.
* 📌 **`tasks.md`**: Task breakdown and unit verification steps.
