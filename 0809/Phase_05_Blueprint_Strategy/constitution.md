# Constitution: Phase 05 — Pedagogical Blueprint Strategy

## 1. Principles
### Rule 1: Mandatory Five-Section Schema
Every generated blueprint MUST contain all 5 sections: `headings`, `text_plan`, `image_plan`, `ca_plan` (historical & recent), and `validation_plan`. Omission of any section constitutes an invalid generation.

### Rule 2: Search Queries Only during Blueprinting
The `ca_plan` MUST formulate precise search queries; it MUST NOT execute live web searches or return search results during Phase 05.
