# Phase 02: Reading, Extraction & Quality Assessment

## Executive Summary
Phase 02 governs Screen 2 (Reading Progress). It verifies document extraction quality, scores text integrity, tracks page boundaries, and executes AI-02A cleanup or AI-02B restructuring if extraction damage is detected.

## Module Breakdown
- `Mod_01_Extraction_and_Page_Mapping`: Page-by-page slicing and mapping.
- `Mod_02_Quality_Heuristics_Diagnostics`: Non-printable ratio and empty-page diagnostics.
- `Mod_03_AI_Cleanup_and_Restructure_AI02A_B`: Canonical AI recovery fallback.
