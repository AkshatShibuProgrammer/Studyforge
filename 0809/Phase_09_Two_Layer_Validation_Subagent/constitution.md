# Constitution: Phase 09 — Two-Layer Validation Subagent

## 1. Principles
### Rule 1: Actionable Suggestions Over Passive Text
Validation MUST NOT present passive summaries. Every reported gap or defect MUST provide an actionable one-click trigger (`Apply Text Revision`, `Fetch Targeted CA`, `Add Container`, `Generate Visual via AI-07K`, or `Ignore`).

### Rule 2: Pass 2 Fact-Check Verification
The validator subagent MUST actively search for and verify claims that reference rapidly evolving numbers (GDP, inflation, budget allocations, statutory limits). Unverified figures MUST be flagged.

### Rule 3: Final Consolidated Trigger Constraint
AI-07I (Final Document Validation) MUST ONLY trigger after all individual parts have attained approved status.
