# Phase 03: Understanding, Deep Extraction & Feature Bundles

## Executive Summary
Phase 03 transforms canonical source text into high-dimensional structural knowledge. It identifies subject/discipline signals (AI-03A), deeply extracts entities with stable IDs (AI-03B), deterministically routes the 12 feature bundles (AI-03C/D), and provides a manual analysis correction editor.

## Module Breakdown
- `Mod_01_Subject_and_Signal_Detection_AI03A`: 12-signal classification.
- `Mod_02_Deep_Core_Extraction_AI03B`: Entity extraction with T-, D-, F-, PYQ- IDs.
- `Mod_03_Smart_Bundle_Router_AI03C_D`: 3-tier bundle evaluation & force-enable.
- `Mod_04_Manual_Analysis_Correction_Editor`: Correction modal with downstream stale invalidation.
